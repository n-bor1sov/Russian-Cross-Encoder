# Examples

A smoke test for the pipeline. Runs end-to-end on a tiny synthetic corpus
with a fixed seed, so a fresh clone reproduces the same inputs.

## What's here

- `data/` — three parquet files (~140 rows total) generated by
  `generate_mini_data.py`. Regenerate with
  `python examples/data/generate_mini_data.py`.
- `configs/` — TOMLs mirroring `configs/thesis/` but with shrunk
  parameters (small `k`, batch size 4, one epoch).
- `.env.example` — paths point under `examples/work/` so the example
  does not pollute the rest of the repo.
- `expected_outputs/` — schema snapshots captured from a clean run.
  Use them to diff your column shapes against a known-good baseline.

## Scripts

- `run.sh` (default) — skips the embedding-API stages. Starts from
  `data/mini_compiled.parquet`, buckets it, trains for one epoch, and
  runs evaluation. No API key required. Expect about ten minutes on a
  single GPU.
- `run_full.sh` — exercises stages 2–5 as well. Needs
  `EMBEDDING_API_BASE_URL` set in `examples/.env`. Then it falls
  through into `run.sh`.

First run will copy `.env.example` to `.env` if you do not have one.

## Outputs

All artifacts go under `examples/work/`. The final metrics land in
`examples/work/eval_results.json`. The directory is safe to delete
between runs (`rm -rf examples/work`).
